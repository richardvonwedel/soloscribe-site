Transkription für Jazzmusiker

Vom Solo auf der Platte zu Noten & Tab.

Soloscribe trennt das Solo aus der Aufnahme heraus und erkennt die Töne, auch Doppelgriffe und Dreiklänge. Daraus werden Notenschrift, Tabulatur und ein mitlaufendes Griffbrett. Alles läuft lokal auf dem Mac.

Jazzgitarre Klavier, beide Hände Andere Instrumente macOS · Apple Silicon

So läuft es ab

Ein Projekt pro Solo. Jeder Schritt lässt sich einzeln neu starten, bearbeitete Noten bleiben dabei erhalten.

Import

Nur den gewünschten Ausschnitt aus einem Video laden oder eine Audiodatei hochladen. Gespeichert wird verlustfrei als FLAC.

Stems

Demucs trennt Gitarre, Klavier, Bass, Schlagzeug und Gesang auf der Apple-GPU.

Beats & Takt

beat_this findet Schläge und Taktanfänge. Ein kurzer Assistent prüft danach Takt, Raster und Tonart mit Metronom-Klick.

Transkription

Ein auf Jazzgitarre trainiertes Modell erkennt die Töne, für Klavier Transkun (beide Hände, Pedal). Andere Instrumente laufen mit basic-pitch.

Was Soloscribe kann

Synchron anhören

Original, Solo-Spur, Band ohne Solo zum Mitspielen oder die Transkription selbst. Langsamer abspielen ohne Tonhöhenänderung, Loops per Taste oder Ziehen.

Fehler hören

„Original + Transkription“ spielt die erkannten Noten leise mit. So fallen falsche Töne sofort auf.

Live-Griffbrett

Der Fingersatz wird automatisch berechnet und berücksichtigt Lagenwechsel, Strecken und Führungsfinger. Die nächsten Töne erscheinen als blasser werdende Punkte.

Noten & Tab

Notensatz mit alphaTab und passendem Raster pro Schlag: Achtel, Sechzehntel, Triolen, 32tel. Swing wird gerade notiert, mit Swing-Zeichen. Druck auf A4 oder als PDF.

Piano-Roll-Editor

Noten verschieben, teilen, zusammenführen, quantisieren, kopieren und einfügen, auch zwischen Projekten. Alles mit Rückgängig.

Klavier

Hände werden automatisch aufs Klaviersystem verteilt. Dazu Pedalzeichen, Fingersätze 1–5 und eine mitlaufende Klaviatur.

Wie genau?

Gemessen auf GuitarSet. F1 je Note: Tonhöhe exakt, Einsatz innerhalb von ±50 ms. 1,0 wäre fehlerfrei.

Noch nicht erkannt werden Bends, Slides, Hammer-ons und Dynamik.

Installation

macOS mit Apple Silicon, Homebrew und Node.js ≥ 20. Der Quellcode liegt in einem privaten Repository, Zugang auf Anfrage.

# Werkzeuge
brew install uv ffmpeg fluid-synth
uv python install 3.11

# Backend: lädt Modell (~100 MB) und SoundFont
cd backend
uv sync
uv run soloscribe setup

# Frontend
cd ../frontend
npm install

# Starten → http://localhost:3000
cd .. && ./dev.sh

Oder im Finder Soloscribe.command doppelklicken. Das Terminalfenster muss offen bleiben, solange Soloscribe läuft.

Soloscribe ist ein Werkzeug zum Üben und Lernen. Bitte nur Material verwenden, das zu Lernzwecken genutzt werden darf. Audio wird nicht weiterverbreitet.
